LABELPRINT / 0.2.0
103 × 199 mm / 824 × 1592 dots
01 / PDF

Den passenden Ausschnitt.

Seite auswählen, Rechteck aufziehen, optional um 90° drehen. Das Original bleibt unverändert.

02 / RASTER

Vorschau bis zum Druckpunkt.

Proportional auf 103 × 199 mm eingepasst, mindestens 3 mm Rand. Vorschau und Druck teilen dasselbe 1-Bit-Raster.

03 / BLE

Ein Klick, ein Etikett.

Direkt per Bluetooth LE zum D520BT. Keine automatische Wiederholung. Bluetooth Classic ist experimentell.

Ein kurzer Weg. Offen nachvollziehbar.

PDF → Auswahl → Raster → TSPL → Bluetooth LE → Papier. Architektur mit Verweisen in den Quellcode; Viewer-Bedienelemente auf Englisch.

Architektur erkunden →

Mit mehreren echten PDF-Varianten auf einem D520BT praktisch geprüft: erfolgreich zugeschnitten, eingepasst und gedruckt, alle geprüften Codes lesbar. Andere Inhalte und Geräte brauchen einen eigenen Test auf Papier.
