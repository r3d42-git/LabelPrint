# LabelPrint 0.2.1

## Deutsch

LabelPrint bekommt ein eigenes App-Icon: ein weißes Etikett mit Barcode auf Grün.

- Neues macOS-App-Icon in allen Standardgrößen, im App-Bundle enthalten.
- Dasselbe Icon im Seitenkopf und als Browser-Symbol auf der GitHub Page.
- Reproduzierbarer Icon-Build; die Release-Prüfung kontrolliert jetzt auch das eingebettete Icon.

Für **Apple Silicon (arm64), macOS 14 oder neuer**. ZIP entpacken und `LabelPrint.app`
in den Programme-Ordner ziehen. Mit Developer ID signiert, von Apple notarisiert und
mit angeheftetem Notarisierungsticket. SHA-256-Datei liegt dem Release bei.

PDF-Auswahl, Einpassen auf 103 × 199 mm und Bluetooth-LE-Druck auf dem Phomemo D520BT
funktionieren wie zuvor. Kein Herstellertreiber, keine Cloud. Deutsche App-Oberfläche,
Dokumentation auf Deutsch und Englisch. 15 automatisierte Tests und digitaler QR-/Code-128-Test.

## English

LabelPrint now has its own app icon: a white barcode label on green.

- New macOS app icon in all standard sizes, included in the app bundle.
- The same icon in the GitHub Pages header and browser favicon.
- Reproducible icon build; release verification now also checks the embedded icon.

For **Apple Silicon (arm64), macOS 14 or later**. Extract the ZIP and move `LabelPrint.app`
to Applications. Developer ID signed, Apple notarized, with the notarization ticket
stapled to the app. A SHA-256 checksum file accompanies the release.

PDF selection, proportional fitting to 103 × 199 mm and Bluetooth LE printing on the
Phomemo D520BT work as before. No vendor driver or cloud. German app interface;
German and English documentation. 15 automated tests plus digital QR/Code 128 verification.

GPL-3.0-only. Independent project, not affiliated with Phomemo or Labelife.
No Intel release or separate clean-machine installation test.
